# 仕様書

小川樹（Ogawa Tatsuki）のポートフォリオサイトの仕様です。コードと表示内容の「現在の姿」を記録します。更新日: 2026年10月3日。

## 1. 概要

| 項目 | 内容 |
| --- | --- |
| 目的 | 採用担当者・エンジニアが、小川樹の人物像、使用技術、成果物、経歴をスクロールだけで把握できるようにする |
| 想定閲覧者 | エンジニア、人事担当者 |
| 公開URL | https://tatsuki821.me/ （`CNAME` で設定） |
| 公開方法 | GitHub Pages（`main` ブランチの内容がそのまま公開される） |
| 構成 | 静的サイト。HTML / CSS / JavaScript のみ。ビルド工程・外部ライブラリなし |
| 言語 | 日本語のみ |

設計方針は「画面遷移を減らし、1ページ（LP）のスクロールで概要が分かること」です。詳しい内容を読みたい人だけが、詳細ページへ進みます。

#### 3.1.1 成果物の横スライド

- デスクトップ（幅761px以上）で、動きを減らす設定でない場合: セクションを縦に長くし、中身を `position: sticky` で固定します。縦スクロール量を横方向の移動量に変換して、カードをスライドさせます。
- スクロールできる距離は「カードの全幅 − 表示幅」に一致します。カードが表示幅に収まる場合は固定せず、横に並べるだけです（実績ページのインターン）。
- 最後までスライドすると（進行度92%超）、「もっと見る」ボタンが現れます。
- モバイル（幅760px以下）または動きを減らす設定の場合: 固定せず、カードを横スワイプ（`scroll-snap`）で見る形に切り替えます。カード幅は画面の約86%です。
- 画面幅の変更やリサイズ時は再計算します。`#works` などのアンカーで開いた場合は、レイアウト確定後にもう一度その位置へ移動します。

## 4. 共通仕様

### 4.1 ヘッダー

- 全ページで固定表示（高さ76px、モバイルは68px）。
- トップ・実績: ページ内アンカーのリンク。詳細ページ: トップ / 制作物 / 経験 / インターン（実績ページの各セクションへ）。
- 1040px以下ではハンバーガーメニュー。開いている間は背景を操作できなくし、Escキー・背景クリックで閉じ、フォーカスをメニュー内に留めます。

### 4.2 レスポンシブ

| 幅 | 変更点 |
| --- | --- |
| 1040px以下 | ヘッダーをハンバーガーメニューに切り替え |
| 760px以下 | 成果物・経験を横スワイプ形式に切り替え、年表・スキルを1列化 |
| 600 / 440 / 390px以下 | 余白・文字サイズの段階的な調整（`portfolio-v2.css`） |

### 4.3 アクセシビリティ

- スキップリンク（「本文へ移動」）、見出し階層、`aria-label`、`aria-current`、フォーカス表示を備える。
- スキルアイコンはキーボードでフォーカスでき、フォーカス時もラベルが出る。
- 新しいタブで開くリンクには `rel="noopener noreferrer"` と、スクリーンリーダー向けの「（新しいタブ）」を付ける。
- 「視差効果を減らす」設定では、横スライドの固定とすべてのアニメーションを無効にし、通常の表示にする。

### 4.4 アニメーション

実装は `css/motion.css` と `js/motion.js` です。全ページで読み込みます。

| 種類 | 動き |
| --- | --- |
| 基本（up） | 下から56px浮き上がり、拡大（0.94→1）しながらフェードイン。0.9秒 |
| カード | 右から64px入る |
| 年表の項目（step） | 左から64px入る |
| スキルアイコン（icon） | 小さい状態から弾むように現れる |
| 順番 | 兄弟要素は110msずつ遅らせる（連絡先・アイコン・プロフィール項目など） |
| 年表の線 | スクロールに合わせて青い光る線が伸び、線が届いた項目の点が光って脈打つ。基準は画面の上から60%の位置。ページ末尾に近づくと基準を画面下端までずらし、最後まで必ず届く |

- 要素は画面に入った時に一度だけ再生します（`IntersectionObserver`、下端8%を除外、可視12%以上）。
- 非表示にするのは、JavaScriptが動き、かつ動きを減らす設定でない場合だけです。JavaScriptが無効でも内容は隠れません。
- アニメーションは `backwards` の塗り方で再生するため、再生後のホバー用の動きと干渉しません。

## 6. 技術仕様

### 6.1 ファイル構成

```
tatsuki.github.io/
├─ index.html              トップ（LP）
├─ pages/                  実績・自己紹介・詳細ページ
├─ css/
│  ├─ portfolio-v2.css     共通の土台（配色・ヘッダー・Hero・ボタン・フッター・自己紹介）
│  ├─ lp.css               LP専用（連絡先・スライダー・スキル・年表・戻るボタン）
│  ├─ motion.css           アニメーション
│  └─ style.css            詳細ページ（事例ページ）用
├─ js/
│  ├─ portfolio-v2.js      ヘッダーのメニュー開閉
│  ├─ lp.js                縦スクロール→横スライドの変換、アンカー再調整
│  └─ motion.js            スクロール表示・年表の線
├─ assets/icons/           スキル・アプリのアイコン（出典は同フォルダの README）
├─ images/back.png         Hero背景
├─ docs/specification.md   この仕様書
├─ CNAME                   独自ドメイン
└─ README.md
```

### 6.2 HTMLの規約

- 成果物スライダーは `section.lp-works > .lp-works-pin > .lp-works-viewport > ul.lp-works-track > li > .lp-work` の構造。ページ内に複数置けます（`lp.js` が全部を処理）。
- アニメーション対象は、`motion.js` の `mark()` に書いたセレクターで指定します。HTMLに属性を書く必要はありません。
- アイコンは `<li tabindex="0" data-name="表示名"><img src="…" alt="表示名"></li>`。ラベルは `data-name` から CSS で表示します。

### 6.3 ブラウザ要件

`IntersectionObserver`、CSS の `:is()`、`position: sticky`、`scroll-snap`、`matchMedia` が使えるモダンブラウザ（Chrome / Edge / Safari / Firefox の現行版）。`IntersectionObserver` がない場合は、アニメーションなしで表示します。

### 6.4 キャッシュ

`portfolio-v2.css` の読み込みには版番号（`?v=…`）を付けています。`portfolio-v2.css` を変更したら、各HTMLの版番号も更新してください。`lp.css`・`motion.css`・JavaScriptには付けていないため、反映されない場合は強制再読み込みします。

## 7. 更新手順

### 7.1 成果物を追加する

1. `assets/icons/` にアプリのアイコン画像（正方形・角丸）を置く。
2. `index.html` の `ul.lp-works-track` と、`pages/achievements.html` の制作物セクションに、`<li>` を1つ追加する。
3. 詳細ページを `pages/` に作る場合は、既存の `work-*.html` を複製し、ヘッダー・戻るリンクの形を合わせる。
4. 枚数が増えると、スライドの距離は自動で延びます。

### 7.2 使用技術を追加する

1. アイコン画像を `assets/icons/` に置き、`assets/icons/README.md` の出典表に追記する。
2. `index.html` の該当する層の `ul.lp-icons` に `<li>` を追加する。学習中・導入予定は `class="is-learning"` を付け、`data-name` と `alt` に「（学習中）」と書く。

### 7.3 年表・資格を追加する

`index.html` の `ol.lp-tl` に `<li><time>YYYY.MM</time><span class="lp-tl-tag">種別</span><p>内容</p></li>` を追加する。種別タグの `span` に、資格は `is-cert`、開発は `is-dev` のクラスを付けると色分けできます（例: `<span class="lp-tl-tag is-cert">`）。自己紹介ページの経歴（`ol.about-timeline`）も合わせて更新します。

### 7.4 Instagram のURLを設定する

`index.html` の連絡先にある `TODO` コメント直下の `href="#"` を、アカウントのURLに差し替える。
