# Skillsページのアイコン

`pages/skills.html` で使う16個のSVGです。すべて [Simple Icons 15.16.0](https://www.npmjs.com/package/simple-icons/v/15.16.0) の `icons/` から、形状を変更せずに取得しました。各SVGは技術・サービスの識別にのみ使用し、各社との提携や認定を意味しません。ページにはアイコンと技術名を併記しています。

Simple Iconsのパッケージ自体はCC0 1.0です（[ライセンス](LICENSE-SIMPLE-ICONS.md)）。ただし[配布元の注意書き](DISCLAIMER-SIMPLE-ICONS.md)にあるとおり、**パッケージのCC0が個々のブランドロゴにも適用されるとは限りません**。次の「未記載」は、Simple Icons 15.16.0のアイコンデータに個別ライセンスが登録されていないことを示し、自由利用を保証するものではありません。ブランドの利用条件は各権利者の案内も確認してください。
