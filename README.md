# Tatsuki Portfolio

[公開サイト](https://tatsuki821.me/) · [要件定義書](Mypage/portfolio-renewal-requirements.md)

## 概要

小川樹の自己紹介、使用技術、実績、資格、連絡先をまとめたポートフォリオサイトです。初めて訪れた人が、ホームの概要から関心のある詳しいページへ進めるようにしています。

| 見たい内容 | ページ |
| --- | --- |
| 経歴やプロフィール | [自己紹介](pages/about.html) |
| 使った技術 | [使用技術](pages/skills.html) |
| 制作物、経験、インターン | [実績](pages/achievements.html) |
| 取得した資格 | [資格](pages/qualification.html) |
| メールとGitHub | [連絡先](pages/contact.html) |

パソコンではヘッダー、スマートフォンではメニューから各ページへ移動できます。主要ページは日本語と英語を切り替えられます。制作物の詳細ページの本文は日本語です。

このリポジトリには紹介サイトのHTML、CSS、JavaScriptを置いています。制作物のアプリ本体は含みません。手元で動かすためのビルドや環境変数は不要です。

## インストール

[公開サイト](https://tatsuki821.me/)を見るだけなら、インストールは不要です。手元で確認する場合は、Gitでリポジトリを複製します。

```bash
git clone https://github.com/OgawaTatsukicreator/tatsuki.github.io.git
cd tatsuki.github.io
```

パッケージのインストールや環境変数の設定はありません。

## 使い方

1. Python 3がある場合は、リポジトリのルートで次を実行します。

   ```bash
   python -m http.server 5501
   ```

2. ブラウザーで [http://localhost:5501/](http://localhost:5501/) を開きます。Pythonを使わない場合は、VS Codeで index.html を開き、「Open with Live Server」を選びます。Live Serverのポートも5501に設定済みです。
3. ホームのカードやヘッダーから各ページへ進みます。実績ページでは「制作物」「経験」「インターン」を切り替え、カードを横にスライドできます。

## 運用

1. 変更を提案する場合は、このリポジトリをForkして作業ブランチを作ります。
2. ファイルを編集し、パソコンとスマートフォンの幅で表示とリンクを確認します。日本語・英語の切替も確認してください。
3. 変更内容をコミットし、元のリポジトリへプルリクエストを送ります。
4. mainブランチへの反映後、GitHub Pagesが公開サイトを更新します。[公開サイト](https://tatsuki821.me/)で表示を確認します。

CSSや翻訳用JavaScriptを変更した場合は、各HTMLの参照URLに付けた版番号（例: `?v=20260929-1`）も更新します。
