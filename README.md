# Tatsuki Portfolio

[公開サイト](https://tatsuki821.me/) · [仕様書](docs/specification.md)

## 概要

小川樹のポートフォリオサイトです。1ページ（LP）構成で、スクロールするだけで連絡先、成果物、使用技術、年表を確認できます。

| 見たい内容 | 場所 |
| --- | --- |
| 名前・連絡先（GitHub / メール / Instagram） | [トップ](index.html) |
| 成果物（4件）・使用技術・年表 | [トップ](index.html) |
| 制作物・経験・インターンの一覧 | [実績](pages/achievements.html) |
| 人生設計・キャリアプラン | [自己紹介](pages/about.html) |

成果物・経験・インターンは、縦にスクロールすると横にスライドして次のカードが現れます。各セクションや詳細ページは、スクロールに合わせてアニメーションします（OSの「視差効果を減らす」設定では無効）。詳細ページの本文は日本語です。

このリポジトリには紹介サイトのHTML、CSS、JavaScriptを置いています。制作物のアプリ本体は含みません。手元で動かすためのビルドや環境変数は不要です。

## ドキュメント

画面ごとの仕様、アニメーション、ファイル構成、更新手順（成果物・使用技術・年表の追加方法）は [docs/specification.md](docs/specification.md) にまとめています。スキルアイコンの出典は [assets/icons/README.md](assets/icons/README.md) です。

## インストール

[公開サイト](https://tatsuki821.me/)を見るだけなら、インストールは不要です。手元で確認する場合は、Gitでリポジトリを複製します。

```bash
git clone https://github.com/OgawaTatsukicreator/tatsuki.github.io.git
cd tatsuki.github.io
```

パッケージのインストールや環境変数の設定はありません。

## 使い方

1. Python 3がある場合は、リポジトリのルートで次を実行します。

   ```bash
   python -m http.server 5501
   ```

2. ブラウザーで [http://localhost:5501/](http://localhost:5501/) を開きます。Pythonを使わない場合は、VS Codeで index.html を開き、「Open with Live Server」を選びます。Live Serverのポートも5501に設定済みです。
3. トップをスクロールして各セクションを確認します（成果物は縦スクロールで横にスライドします）。成果物の「もっと見る」から実績ページへ、年表の「小川樹についてもっと知る」から自己紹介ページへ進めます。

## 運用

1. 変更を提案する場合は、このリポジトリをForkして作業ブランチを作ります。
2. ファイルを編集し、パソコンとスマートフォンの幅で表示とリンクを確認します。確認項目は[仕様書のチェックリスト](docs/specification.md)を参照してください。
3. 変更内容をコミットし、元のリポジトリへプルリクエストを送ります。
4. mainブランチへの反映後、GitHub Pagesが公開サイトを更新します。[公開サイト](https://tatsuki821.me/)で表示を確認します。

CSSやJavaScriptを変更した場合は、各HTMLの参照URLに付けた版番号（例: `?v=20260929-1`）も更新します。
