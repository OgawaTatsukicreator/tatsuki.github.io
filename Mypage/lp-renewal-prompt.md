# ポートフォリオ LP化改修プロンプト

以下をそのまま Claude Code への指示として使用する。

---

## 前提

`tatsuki.github.io` は小川樹（Ogawa Tatsuki）のポートフォリオサイトである。閲覧者は **エンジニアおよび人事担当者** を想定する。
現行サイトは画面遷移が多く、ポートフォリオとして UI/UX が分かりにくい。そこで、現行フォルダを別フォルダ（`Mypage/newPortfolio/`）に移行し、その中の既存コードを改修して **スクロールだけで概要が分かる LP（1ページ構成）** に作り替える。

- 既存の `index.html` / `css/portfolio-v2.css` / `js/portfolio-v2.js` / `pages/*.html` を流用・再編する。
- 配色（チャコール系）、フォント（ヘッダーの Caveat 手書きロゴ等）、既存ヒーロー画像 `images/back.png` は踏襲する。
- 元フォルダ（リポジトリ直下）は変更しない。削除・上書きは新フォルダ内に限る。

## ページ構成（上から順にスクロール）

```
エントリーポイント(Hero) → GitHub/連絡先 → 成果物 → 開発ツール → 年表
```

### 1. エントリーポイント（Hero）
- 既存のヒーローセクションをそのまま採用する。
- 表示する情報：**名前 / 年齢 / 出身地 / 学校**、および「Ogawa Tatsuki のポートフォリオ」であることが一目で分かる表記。
- 年齢・出身地・学校は現行値を使う（21歳〔2026年9月時点〕/ 静岡県伊東市 / 日本工学院八王子専門学校）。

### 2. GitHub・連絡先
- **GitHub・メール・Instagram** のアイコンを **横並び** で表示し、それぞれ該当リンクへ飛べるようにする。
- GitHub: `https://github.com/OgawaTatsukicreator` / メール: `g024c1045@g.neec.ac.jp`（mailto）。
- Instagram の URL は未確定。ダミーのプレースホルダー（`#` と TODO コメント）で実装し、後で差し替えられるようにする。
- アイコンには `aria-label` を付け、新しいタブで開くリンクには `rel="noopener noreferrer"` を付ける。

### 3. 成果物（Works）
- 成果物は **4種類**（顔マスク処理アプリ / KYOTABI＋ / シフト提出システム / マソ君の日常）。
- **横並びのカルーセル型**にし、画面上には同時に **2つ** だけ見える。
- 3つ目以降は、**縦にスクロールすると横方向にずれて現れる**（スクロール連動の横スライド。sticky + 縦スクロール量を横移動に変換する方式を想定）。
- 各カードのアイコン／サムネイルを押すと、その制作物の **詳細ページ**（既存の `pages/work-*.html`）へ遷移する。
- カードには、制作物名・年月・一言説明・使用技術を簡潔に載せる。
- 成果物セクションを最後までスクロールしたところに **「もっと見る」ボタン** を表示し、制作物と経験をまとめた実績ページ（既存の `pages/achievements.html`）へ遷移させる。

### 4. 開発ツール（Skills）
- 属性（**フロントエンド / バックエンド / インフラ / 開発ツール**）ごとに分け、**アイコンのみ**で表示する。
- 見せ方は、グラフのように並べる案か、属性ごとにセクションを分けて縦に並べる案のどちらか。実装前に両案を短く比較し、閲覧者が読み取りやすい方を選ぶ。
- アイコンは `assets/icons/` の既存 SVG を使う。各アイコンにはツール名を `aria-label` / `title` で付与する。
- 「使用済み」と「学習中・導入予定」を、見た目（濃淡など）で区別する（現行 `skills.html` の区別を踏襲）。

### 5. 年表（Timeline）
- **高校から現在まで** の経歴を軸に、時系列で並べる。
- 既存の経歴（サッカー引退、専門学校入学、基本情報技術者試験合格、マッスルゲート入賞、パーソナルトレーナー開始、シフト提出システム開発、ビジネスコンテスト2位、ハッカソン、インターン等）と、資格取得年月を統合する。
- 高校時代の情報は現行サイトに少ないため、不足分は推測で書かず、TODO として一覧にして私に確認する。
- 年表の最後に **「小川樹についてもっと知る」ボタン** を置き、人生設計・キャリアプランを見られるページ（既存の `pages/about.html`）へ遷移させる。

## 共通要件

- ヘッダーは固定で、各セクションへのアンカーリンク（GitHub / 成果物 / 技術 / 年表）を置く。スマホではハンバーガーメニュー。
- スマートフォンでも崩れないレスポンシブ対応。成果物の横スライドはモバイルでは1枚表示に調整する。
- 言語切替（JP/EN）は今回は廃止し、LP が日本語で完結する形にする（理由：LP化で文言が大きく変わるため）。
- アクセシビリティ：キーボード操作、フォーカス表示、`prefers-reduced-motion` で横スライドや出現アニメーションを無効化し、通常の縦並びにフォールバックする。
- 外部ライブラリは使わず、素の HTML / CSS / JavaScript で実装する。
- 不要になったファイル（旧 i18n、旧 CSS/JS）は整理するが、削除前に一覧を提示して確認を取る。
